# Changelog

Changes a user would notice. Versions are git tags.

## Unreleased

- `expert-plan` (draft, `metadata.internal`): plans a task in rounds of numbered questions, each with what it changes in the plan and a recommended answer, then writes the plan in the `expert` format once the user confirms. The questioning draws on assumption mapping (Bland and Osterwalder), value of information (Howard), past behavior over opinions (Fitzpatrick), alternatives and the decision hierarchy (Spetzler, Winter and Meyer), reversibility and kill criteria (Duke), the outside view (Kahneman and Lovallo) and a premortem with the user (Klein). Six eval cases, 6/6 passed on Claude Sonnet (2026-11-27). Four external models (Gemini Neon, Gemini Hydrogen, DeepSeek, GPT Luna) judged the answers blind against an earlier version and each scored the new one higher (40 to 38, 47 to 44, 48 to 46, 42 to 40); the last small fixes from that review were checked by rerunning the evals, not judged again. Later in the same draft: a backcast after the premortem, who carries out the work and who can block it, Duke's Only-Option Test, a weakest-link check before asking to write the plan (at most one question), one decision per number with a split test run before each round, and a tool choice that waits for the round after its context questions. The same four models judged it against the first commit blind, before the split test and the tool-choice change, and three scored it higher (41 to 40, 50 to 44, 48 to 46; Luna 39 to 41); those last two changes were checked by rerunning the evals only. The same four models then judged it blind against the author's own past rounds (two of `grilling`, one of `expert`), replayed on snapshots of the projects from those dates (the replies could still read some live state), and it won all twelve case-and-judge pairings (7 to 9 against 3 to 6). From their shared findings: the outside-view question asks only how long it took; a fact that lives only with the user never gets an invented value or cause, only what they said, what was found, or a neutral default marked as one; the split test also covers the recommendation; "yes to all" always accepts every recommendation; the exception that let parts feeding one decision share a number is gone; and the last round no longer waits behind a context round when a tool choice is still open. What made others give up is now asked in the premortem, and the last-round plan sketch assumes the recommended option. Evals: 6/6 passed twice on Claude Sonnet (2026-11-27), 10 of 12 meeting their judge lines by hand; the premortem case then deferred its last round in 2 of 5 runs, and after the last-round fix met it in 4 of 4 (one restarted the numbering at 1). Replies in Portuguese to an English message appeared in 3 of 4 runs that day and in 1 of 3 runs of the previous version, so they do not come from this change. Still open: numbers that join two separable decisions (up to half of one first round), and recommendations that add a second choice ("yes, and the rule goes in the project file").
- `expert`: before naming the field, restate the deliverable's noun as the verb it must accomplish (Kelley and Littman), and the external check now includes at least one check the session runs itself, with a person's judgment on top. Three new eval cases (churn analysis, an assumed cause, a QBR deck). Evals: 7/7 passed on Claude Sonnet before and after (2026-11-26). Judged against its judge line, the deck case met neither point on the old version (0/3 runs) and met both on the new one (3/3, plus 1/1 on the final wording after an external review); the churn and assumed-cause cases already passed on the old version, so they guard against regression only.
- `gemini-web`: `--mode tasks` now runs a Gemini Task (the app's agent mode). It needs `--allow-actions` (replaces `--confirm-apps-off`), is sent at most once, is never retried, stays in web history, and exits 6 when a reply arrives (refusals and error notices included, usage limits excluded) but the stored turn does not confirm Tasks mode. A task reply is still printed or written to `--output` when the exit code reports a failure, a blocked re-send reports the first send's error (exit 2 on 401/403), and `--estimate` needs no `--allow-actions` (22 credits measured on `hydrogen`, 49 on `neon`). A request patch that does not apply (tasks or medium effort) now exits 6 at once instead of after about 75 s of library retries. Verified with three tasks on one account (2026-11-26), before the last error-handling fixes, which were checked by the selftest and a free read of stored turns. Selftest: 232/232 checks passed (Python 3.15 and 3.12); evals: not run, the nested `claude -p` sessions were not logged in.
- `gemini-web`: wrapper around your own logged-in Gemini web session (text chat, clean attached files, image generation/editing, short video, and unconfirmed Deep Research) with offline guards, per-run cookie cache isolation, and venv auto-detection. Selftest: 98/98 checks passed; evals: 6/6 passed on Claude Sonnet (low effort, dry-run, 2026-11-24).
- `gemini-web`: add `--quota` (0-credit balance check), deterministic stderr quota warnings (`>=50%`, `>=75%`, `>=90%`) and window reset times on exit 4, mode-based default `--model` (`carbon` for `image`/`video`, `hydrogen` for `chat`/`research`), `--aspect W:H` (verified full-bleed on `carbon` 16:9/9:16/4:5 and `hydrogen` 16:9), `--prompt-file` (with `openat`/`O_NOFOLLOW` symlink guards and JSON media framing), `--cookies-file` / `GEMINI_WEB_COOKIES_FILE` / default `cookies.json` fallback (for Windows App-Bound Encryption and locked keyrings, with `0600` POSIX permission checks and strict `*.google.com` filtering), swapped image/video mode hints, art-direction rules in `references/media.md`, and measured per-model image routing (`carbon`/`gemini-auto` -> `Nano Banana 2 Lite`, `hydrogen`/`neon` -> `Nano Banana 2.1`). Selftest: 221/221 checks passed (Python 3.15 and 3.12); evals: 6/6 passed on Claude Sonnet (low effort, dry-run, 2026-11-24).
- `scripts/eval.py`: add per-case fixture files (text and `base64:`, rejecting traversal and symlinks), suite/case `env`, `allow_edits`, `--effort`, and `--setting-sources project` isolation.
- Skills no longer carry `metadata.status`; only drafts set `metadata.internal`. `scripts/link-skills.sh` now links every skill folder. `expert` and `gemini-web` instructions are unchanged (frontmatter only, evals not rerun).
